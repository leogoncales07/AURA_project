# Contexto e prioridade da AURA

- Projeto de Prova de Aptidão Profissional (PAP) de um curso técnico.
- Responsáveis: Leonardo Pierre Gonçales e Matheus Esaka Silva.
- Objetivo atual: completar e estabilizar backend, web e mobile, com testes e documentação úteis para a PAP.
- A publicação da web está adiada. O professor irá tratar da aquisição do domínio e das licenças. Não solicitar contas de alojamento nem avançar com publicação nesta fase.
- `aura.pt` foi uma ideia de endereço; a sua propriedade não está confirmada.
- O mobile está a ser testado num telemóvel físico com Expo Go, carregando o bundle servido pelo computador.
- Manter o desenvolvimento compatível com esse fluxo. As funcionalidades dependentes de configuração nativa exigem validação posterior numa build própria.
- Os testes na rede local devem usar o endereço Wi-Fi do computador; `localhost` no telemóvel refere-se ao próprio telemóvel. Supabase já está configurado e validado; os testes locais usam esse mesmo projeto.
- A preparação de publicação existente é documentação para o futuro, não uma instrução para publicar agora.
